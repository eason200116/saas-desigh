1 · 背景

旧后台 SitINR（.NET 单体）沉淀了完整的会员运营能力，但功能高度集中在「巨型」控制器中、缺乏多商户隔离，难以直接支撑平台的 SaaS 化运营。本期在将这些能力按新分类体系深度迁移至 V3 多商户后台的同时，统一交互骨架、补齐商户级数据隔离，并新增两项关键能力：一是回答「会员从哪儿来」的归因体系，二是打通广告投放获客的推广分发配置。

2 · 需求目的

把旧后台 SitINR 沉淀的会员运营能力，按多商户 SaaS 的方式深度迁移到 V3 后台，并补齐三件事：商户级数据隔离、回答「会员从哪儿来」的归因体系、打通广告获客的推广分发配置。一句话——让平台能以「多商户」的姿势，统一、可溯、可复制地运营会员。

2.1 目标

  • 迁移补全：对照 SitINR 补齐会员相关功能并按新分类重新归属，本期落地 22 个功能页。
  • 导航重组：8 大主 Tab 改为多列分组下拉（mega menu），「风控管理」「配置中心」由会员子项提升为一级模块。
  • 归因可溯：注册即按优先级判定来源并一次性固化，会员详情完整呈现获客链路。
  • 获客闭环：推广分发配置打通「域名 → 渠道 → 推广 → 获客归因」闭环的前半段。
  • 体验一致：全部列表页复用同一套筛选 / 表格 / 工具栏 / 弹窗骨架，贯彻多商户隔离。
  • C 端本地化：面向会员的消息文案与配图统一升级为「逐语言维护」（每种语言各存一套、默认语言必填、缺译回退默认），消息模板配置迁入配置中心套模板化范式，支撑多商户多语言运营。

2.2 五大交付物

① 会员管理深度迁移（22 页） ·  ② 顶部导航分类优化（mega menu） ·  ③ 多标签页签栏 ·  ④ 会员详情归因字段 + 会员列表增强 ·  ⑤ 推广分发配置（渠道/域名/防封救援/解析检测）

3.1 多商户模型

数据以「商户」为唯一组织维度（现阶段不设集团 / 市场上级层级），所有功能在商户维度上严格隔离；现阶段仅一个「商户」角色（不细分子角色），但后台支持跨商户的查询与配置。同一功能围绕「看哪些商户 + 一套参数怎么省力铺给一堆商户」分三种形态：

形态做法用于
① 分数据查询筛选区「商户」下拉：多选 + 顶部「全部」（与具体商户互斥）、空值=全部、不再必填、总控端扁平多选。个别需按单一商户口径查的页面（如会员列表）改为「单选 + 必填」：无「全部」、不可清空、必选一个、占位「请选择商户」（商户筛选组件按页支持多选 / 单选两种模式）会员 / 运营 / 报表 / 风控 列表
② 模板化配置多套模板 +「选商户 → 保存 → 发布」+ 复制模板到其他商户VIP 配置 / 返佣配置
③ 单站点配置顶部商户切换条，切谁配谁，一次只配一个商户注册管理 / 语言 / 开关参数配置

4.2 权限说明（角色与菜单权限）本期新增

后台账号"能看哪些菜单、能做哪些操作"由角色统一管控。本期把「系统管理 · 角色管理」的「分配权限」能力补全并升级，作为功能补充介绍如下（控件级交互见「交互规则 · 系统-角色管理」）。

能力说明
角色管理可新增 / 编辑 / 删除角色（角色名 + 描述 + 启用 / 停用开关）；删除等危险操作二次确认。
分配权限（核心）给选中角色按三级菜单树勾权限：模块（会员 / 运营 / 财务 / 游戏 / 配置 / 报表 / 风控 / 系统 / 数据分析 / 商户）› 页面（如会员列表 / 分组管理…）› 操作（查看 / 新增 / 编辑 / 删除 / 导出 / 审核 / 发布 / 批量导入…）；父子级联勾选，支持按菜单名搜索、全选 / 全部展开。
覆盖范围权限树已补全为目标站全部可见菜单：10 模块 / 64 页 / 184 个操作权限；隐藏页与「待定」页不纳入。
新增标记2.0 新增的模块 / 页节点带可一键去除的「新」小标（共 2 模块〔配置中心 / 风控管理〕+ 25 页），便于迁移期识别新功能；「角色管理」本身也标「新」。

4.3 非功能简介

  • 数据真实性：数据 / 交互取自源（SitINR 源码 / UAT），无源标「新」并先确认，不臆造。
  • 商户隔离：筛选区商户首位 + 表首商户列 + 商户视角隐藏该列 + 切换即时重渲染。
  • 真实交互：导出 / 搜索 / 排序 / 保存 / 删除均真实生效，每步配 Toast。导出统一改为「先选格式再导出」——点击导出先弹格式下拉，选 Excel（.xlsx）或 CSV（.csv）后才下载（全站带导出按钮的页面一致）。
  • 埋点合规：基础事件（激活 / 注册 / 登录 / 首充 / 付费）强制上报，作为归因采集依据。
  • 脱敏：手机 / 邮箱 / 卡号脱敏，按权限展示完整值。
  • 反馈一致：Toast 3 秒消失；危险操作二次确认；弹窗点遮罩不关闭；校验失败标红 + 错误面板。
