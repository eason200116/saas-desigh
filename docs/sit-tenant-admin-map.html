3. 通用控件规律 全局一致

  • 筛选区 商户 * 永远居首必填 → 高级条件 → 时间范围(中间 → 箭头)→ 蓝色 搜索/重置/收起·展开;复杂页支持「高级筛选」折叠(前5主筛选+其余折叠)
  • 日期快筛(两套范式) 业务列表:今天/昨天/本周/上周/本月/上月/所有;层级类:上一日/下一日/日/日区间/月/所有(逐日导航)
  • 状态快筛 Tab 横排(全部/待派发/待审核/审核中/审核超时/已提交…),当前态高亮
  • 操作列 纯文本链接:查看详情/编辑(蓝)、删除(红)、转派/充值通道管理/权限编辑(下钻)
  • 状态表达 启用=绿色 tag,或行内 蓝/灰 toggle 开关(银行字典、IP白名单)
  • Tag 体系 币种(USDT绿/INR/VND)、商户号、内置类型(本地银行卡/三方法币/三方Usdt)均用胶囊 tag
  • 数据脱敏 卡号 646***545、手机 841***890
  • 多行单元格 一格堆叠多条(订单时间含 申请/派单/更新)
  • 批量操作 底部「全选当前页 + 批量操作」,或顶部专项按钮(批量转派/批量赋权/批量google操作/批量拉黑)
  • 导入导出 / 自定义列 几乎每个列表右上角都有「⚙ 自定义列」,数据页有「导出」
  • 辅助提示 蓝色信息条(权限说明)、红色约束提示(仅保留近60天订单、必须填写一项、日期跨度限制)
  • 分页器 统一 共N条 ‹ 1 2 … › │ 10/页 │ 跳至 __;部分带「页面总计/总计」页脚合计(金额/U额)
  • 多时区 详情弹窗内申请时间可按业务地显示(如印度 UTC+5:30),与系统 UTC+7 并存

4. 命名规律

  • 后缀统一 …管理(功能模块)/ …列表·记录(查询)/ …配置(设置)/ …类型·大类·通道(分类)/ …字典(基础数据)
  • 术语统一 商户、会员、订单、三方、代收/代付、出款/入款、审核、层级/下级、提现大类/玩法类型 —— 全站一致
