## 原型归档

- [总控端原型源码](AR前端自定义配置-总控端原型-源码.zip)
- [总控端原型源码素材](AR前端自定义配置-总控端原型-源码素材.zip)

- [商户端原型构建产物](AR前端自定义配置-商户端原型-构建产物.zip)

原型以假数据覆盖主要业务状态，不将接口实现状态呈现在产品界面。源码与构建产物分别归档；总控端与商户端源码均拆分为“源码”和“源码素材”，使用时将同一端的两个压缩包解压到同一目录结构。运行方式以源码压缩包内的 `README.md` 与 `package.json` 为准。

为避免污染 `master` 现有原型，本次不修改仓库现有源代码、脚本、路由、依赖或既有原型目录，仅在本目录保存本项目已修改内容与独立原型归档。

## 发布信息

## 验收口径

- 总控端与商户端的模板、版面、下派、保底、覆盖、域名、多语言、游戏、权限、发布与回滚规则，以 PRD 为产品依据。
- 接口与字段分别在独立章节及独立文件维护，并通过功能点编号与验收案例追溯。
- 原型用于界面、交互和状态验收；正式接口接入不属于本次原型发布范围。
- 手机预览基准为 375 × 812；PC 预览以 1920 为设计宽度并按可用画面自适应，高度不限制。
