① 基本信息组

17 字段 · 3 新增
字段名词解释应用场景异常情况
会员IDmemberId会员在本商户内的唯一数字编号，账号主键，全程不变。所有模块数据关联主键、客服与风控检索定位。仅商户内唯一（跨商户须配商户号）；注销后不复用、不可修改。
商户merchantId会员所属运营主体（数据隔离边界），如 (1050)daman。多商户隔离、权限与经营责任归属。在 A 注册的会员进入 B 视为 B 的新会员；会员/钱包/订单不跨商户混用。
账号account会员登录账号（多为手机号/邮箱，脱敏展示，如 919***888）。登录凭证、客服检索、账号体系唯一性。完整值需权限查看；改名/换绑须验证并留审计。
绑定(邮箱/手机号)contactBind账号已绑定的邮箱与手机号（脱敏）。找回密码、安全验证、消息触达。未绑定时为空；换绑需二次验证并留痕。
语种language会员界面语言（如 hi=印地语），随市场本地化。活动/消息文案语言匹配、客服分流。与市场默认语不一致时以会员设置为准。
会员余额balance会员主钱包可用余额（以经营币种计）。下注/提现资金来源、资产核对。须与资金账变勾稽，不一致即冻结核账。
三方余额thirdPartyBalance沉淀在三方游戏厂商处、尚未归集回主钱包的余额。游戏内资金核对、一键回收、对账。三方接口异常时显示可能延迟，以对账结果为准。
未开奖下注金额pendingBetAmount已下注但尚未结算（开奖）的在途金额。在途资金统计、提现可用额与风控计算。长时间未结算→挂单/结算异常排查。
充值等级rechargeLevel按累计充值评定的等级（如 L3）。充值激励档位、专属活动门槛。按规则周期评定，不随单次回撤即时降级。
首次登录firstLoginTime会员账号的首次登录时间。激活分析、新客生命周期起点。与注册时间差距过大→疑沉默后激活。
注册时间registerTime会员账号的创建时间。注册趋势、留存与队列（cohort）分析基准。固定不可改；早于首次登录属正常，晚于则数据校验。
会员状态userStatus账号启用/停用状态。登录与交易准入控制、封禁管理。停用后不可登录/交易并留审计；与代理状态相互独立。
会员备注remark运营/客服对会员的人工标注。高价值或风险标识、客服上下文承接。仅内部可见，含敏感信息须脱敏处理。
会员类型userType真实会员 / 内部号 / 测试号等分类。报表剔除内部号、风控与计佣区分。内部/测试号应排除经营指标，错标致数据失真。
邀请人新增inviterId邀请码发起人 ID（通常=直接上级代理），点击可下钻该会员详情。裂变追踪、代理树构建依据、佣金归属判定。无邀请码注册则为空；邀请人被注销/冻结时，代理关系仍保留快照不随之改写。
访问端新增accessClient最近一次访问的客户端类型，枚举 pc/h5/安卓/ios/安卓壳包/ios壳包。设备分布分析、端侧问题定位、APP 下载引导、风控识别。壳包内 WebView 以外层壳判定；UA 被篡改/无法识别时记「未知端」并保留原始 UA。

② 归因来源组 ※ 整组新增

主归因新增mainAttribution注册来源唯一归类（自然流量/广告投放/官方直推/邀请来源 + 未知），优先级唯一、命中即停。获客成本核算、渠道质量评估、ROI 分母；报表按主归因拆分。邀请链接+UTM 并存→判邀请来源，UTM 留辅证并标「裂变获客」；全部无法识别→未知来源并记失败原因。
推广平台名称新增promoPlatform识别出的外部推广平台。带平台点击ID精确识别：Google（gclid）、Meta/Facebook（fbclid）、TikTok（ttclid）、Bing（msclkid）；经 utm_source 识别：Instagram、YouTube、Telegram、WhatsApp、X（Twitter）、Snapchat、Kwai、ShareChat、Line、Zalo；以上均未命中或无参数 → 其他。广告投放平台维度效果与对账；KOL/平台归集。多平台参数冲突按点击ID优先级判定；不可识别→其他；App 安装归因另行设计。
注册渠道新增regChannelId注册时命中的后台定义渠道ID（如 pc001=Facebook推广1），挂在域名之下的来源归因容器。渠道维度注册转化统计、渠道质量与结算。未命中任何渠道→落该经营单元默认自然流量兜底渠道（不可删除/不关注册）；渠道关闭不改历史快照。
登录渠道新增loginChannelId会员最近一次登录命中的渠道ID，可与注册渠道不同。活跃来源分析、再营销渠道评估、回流入口判断。直接访问无渠道参数时显示默认/空；跨商户域名进入应判异常并拦截。
搜索引擎新增searchEngine由 referrer 来源域名识别。可识别引擎：Google、Bing、Yahoo、Yahoo! Japan、DuckDuckGo、Ecosia、Startpage、Brave Search、Ask.com、AOL、Mojeek、You.com、Perplexity、Qwant、Swisscows、MetaGer、SearXNG、Lycos、Excite、Dogpile、OneSearch、Gibiru、Presearch、Yandex、Mail.ru、Rambler、Naver、Daum、goo、Seznam、Onet、WP（Wirtualna Polska）、Coc Coc、Sapo、Eniro、Najdi、Walla；中国引擎（百度/搜狗/360/神马等）及未列出者一律归「其他」；无 referrer 记直接访问。SEO 效果评估、自然流量质量。referrer 被剥离（隐私模式/referrer 策略）→记直接访问；非搜索来源（如经 Meta 进入）→其他。
邀请码新增inviteCode会员注册实际使用的邀请码，关联邀请人/代理ID。代理树绑定、裂变奖励触发、邀请人佣金归属。码失效/过期/跨商户→可注册但不绑代理并记原因；活动邀请码额外记 invite_activity_id。
邀请类型新增invite_type邀请来源细分：正常邀请（invite_type=normal，个人邀请）/ 活动邀请（invite_type=activity，裂变获客，含 invite_activity_id）。区分纯邀请与活动裂变；活动邀请触发活动奖励并标裂变。活动码过期但邀请链接有效→降级为正常邀请；两类标记冲突时以活动邀请优先并记原因。

今日/累计充值depositToday / depositTotal会员当日及历史累计成功充值金额。充值贡献分析、价值分层、首充/复充判断。仅计成功到账，撤销/失败/挂起不计。
今日/累计提现withdrawToday / withdrawTotal会员当日及累计成功提现金额。资金流出监控、净存核算。审核中/驳回不计入成功提现。
今日/累计充提差netDeposit充值减提现的净值（今日/累计），即会员净存。平台留存资金核心指标、盈利能力评估。负值表示净流出；须与充值、提现分项勾稽一致。

今日/累计活动优惠bonusToday / bonusTotal当日及累计获得的活动优惠/赠送金额。活动成本核算、羊毛党识别、优惠占比监控。优惠占比/赠送占比过高→活动滥用风控。

⑥ 代理数据组

15 字段 · 9 新增
字段名词解释应用场景异常情况
一级代理新增rootAgentId该会员所在代理树的顶级（根）代理。总代业绩归集、分成顶层、大代理线监控。自身即根则显示自己/空；代理线超最大层级后新增不再挂树。
总获得佣金totalCommission该会员作为代理累计获得的全部佣金。代理业绩评估、结算核对。须与佣金明细勾稽，不一致核账。
邀请奖励inviteReward因邀请下级而获得的奖励累计金额。裂变激励核算、邀请效果评估。虚假邀请/对刷奖励追回。
下级数量subordinateCount该代理名下下级会员总数（按口径含全部下级或直属）。代理规模评估、团队体量监控。注销下级是否计入按口径定义；出现闭环则异常。
合伙人奖励partnerReward合伙人计划累计获得的奖励金额。高级代理/合伙人激励核算。达标条件核验，未达标不发放。
是否领取返佣rebateClaimed该会员是否已领取其返佣（已领/未领状态）。可配置开关，切换需二次确认。返佣发放状态跟踪、对账。已领/未领状态须与返佣账目对账一致。
直接上级代理新增parentAgentId代理树中该会员的直接父节点（=邀请人）。一级返佣计算、直属关系展示。平台直客无直接上级；不提供转代，划拨只改经营归属不改代理树位置。
代理层级新增agentLevel当前深度 / 最大允许层级（如 3 / 10）。多级返佣分成层级、防无限级嵌套。达上限后下级不再建代理关系；层级数须与代理路径长度一致，否则告警。
代理路径新增agentPath根→本会员的完整代理 ID 链。超过 3 层时仅展示「一级 → … → 直接上级 → 本人」（中间层折叠），点击查看整条线全部代理信息。上下级关系核查、多级返佣溯源、闭环排查。≤3 层时全量展示不折叠；路径出现重复 ID→闭环异常；中间代理注销→以快照为准。
佣金模式新增commissionMode代理收益方式两类：返佣=投注流水返佣 / 返利=亏损分成返利。代理结算口径、不同代理线差异化激励。同线不同级可不同模式；模式变更只对变更后业绩生效，历史按原模式结算。
返佣等级新增rebateLevel会员自身的返佣等级/档位，决定其投注流水返佣比例（如 Lv3=0.5%）。返佣计算、等级化激励、与 VIP/活跃度联动调整。等级变更只对变更后流水生效，历史按原等级结算；无返佣资格时为 0 级/空。
是否给上级返佣新增rebateToUpline该会员产生的有效投注流水是否为其上级代理计提返佣。可配置开关，切换需二次确认。控制返佣链路；内部号/测试号可关闭不计佣。关闭后上级不再因其流水获佣，但代理树关系保留；与代理状态独立。
代理状态新增agentStatus代理资格状态（生效/冻结/注销），与会员账号状态独立。冻结作弊代理返佣但不影响其玩家身份；注销取消资格保留历史。账号启用但代理冻结/注销时，下级业绩不再计佣；状态变更留审计。

6 字段
字段名词解释应用场景异常情况
