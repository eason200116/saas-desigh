全站控件颜色取自 3100 原型主题 token（主色默认 #009688）。一种颜色 = 一种含义，不得混用：青绿 = 可点 / 主操作，绿 = 成功 / 启用，橙 = 警告 / 待办，红 = 危险 / 失败 / 校验错误，灰 = 只读 / 禁用。下表是各页彩色按钮、链接、状态 Tag、红字字段背后的统一口径。
色值角色用在哪些控件交互态 / 备注

通用交互规范 · 补充 新

以下为贯穿全站的通用交互约定（取自 3100 目标站现行实现），各功能页未单独说明处一律按此执行；与上方「通用骨架」配合阅读，下文逐页不再重复。
  • 保存/发布两段式提交（配置类页统一：注册管理 / 系统参数 / 配置开关 / 前台配置）：点「保存」先弹「保存预览」确认框列出本次将保存的内容，确认后才落库，提示「已保存（草稿），点击发布后对外生效」；点「发布」再走「确认发布」二次确认，确认后才对外生效（提示「已发布」）。保存=存草稿、发布=上线，两步分明。
  • 校验保存/发布前先校验，失败必红框标出出错字段并指明错在哪（顶部错误面板 + 字段红框）；行内表格用单元格 invalid 高亮 + errorTip 悬浮说明；业务规则校验（如同级五大类费率之和 >4%）直接拦截并标红，不放过。
  • 操作列永远在最后一列、默认右侧冻结（横版 / 竖版都冻结、不可取消冻结），横向滚动时操作列始终可见。
  • 自定义列列 >10 出「自定义列」：勾选保存后才生效；锁定列（lockFixed）在自定义面板里不可取消勾选、不可拖拽排序，只能显隐其它列；列内容默认居中对齐。
  • 导出按钮仅「报表类页面」或「列数 >20」的列表才提供「导出」，其余列表一律不放；导出点击真实下载 CSV + Toast。
  • 合计行含统计意义的列表带「本页合计 / 总计」行，金额随筛选实时刷新。
  • 编辑形态行「编辑」按页面约定为弹窗编辑或页内编辑（不混用，以各页说明为准）；新增/编辑弹窗自带「取消 / 确定」并就地校验。
  • 二次确认删除 / 拉黑 / 禁用等危险操作、以及行内开关切换，均弹二次确认后才执行并 Toast；危险操作主按钮用红。
  • 顶部多标签页面顶部的多标签页签条支持按住左右拖动 / 触控板横滑滚动、拖拽排序、关闭（含关闭其它 / 左侧 / 右侧 / 全部）；当前页签主色高亮。
  • 二级分类导航左侧分类锚点（系统参数 / 配置开关等）点选后，右侧对应卡牌边框 + 标题高亮，并随内容滚动联动高亮。
  • 横向溢出卡片 / 内容平铺超出宽度时，可左右拖动滚动条查看（如可注册手机号区号卡片）。
  • 图片 / 二维码列表缩略图、收款二维码、凭证图等均可点击 / 悬停放大预览；上传走 image-card（点击上传 + 缩略图预览 + 删除）。
  • 「新」标记本期迁移新增的字段 / 列 / 功能带可一键移除的「新」角标，便于评审区分新旧；正式上线后统一去除。
  • 设备术语全站「设备」口径固定 7 种：H5 / PC / 安卓原生 / iOS 原生 / 安卓壳包 / iOS 壳包 / PWA（不再用「端」字）。
  • 商户隔离顶栏切换商户 → 列表 / 配置按该商户整体重渲染、数据隔离，并隐藏「商户」列。
  • 空态 / 格式无值统一显示「-」；金额千分位；时间按商户时区展示；脱敏字段（手机号等）打码。
  • 操作反馈导出 / 搜索 / 排序 / 保存 / 删除 / 状态切换等每个真实操作都配 Toast，非占位。
