五、推广分发配置 二阶段核心

位置：运营管理 → 推广配置。把 域名 → 打包/PWA → 渠道 → 埋点 串成投放配置链，支持 安卓APK / iOS原生 / 安卓壳包 / iOS壳包 / H5链接 / PWA 共 6 种分发形态。

5.1 推广配置流程（标准作业 SOP）

推广配置按以下顺序在各功能页逐项完成；每阶段标注 负责角色 / 操作步骤 / 验收检查点 / 交付产出。
1 域名准备→ 2 物料打包 / PWA→ 3 渠道绑定→ 4 埋点回传→ 5 投放监控
  • 每个字段来源真实模块下拉：域名 ← 域名管理、渠道 ← 渠道管理、埋点平台 ← 埋点配置
  • 打包管理按分发形态动态配置：APK 传 .apk + 应用名/版本/打包域名；壳包传壳包 + 壳访问URL；H5 / PWA 免打包（提示 + 跳 PWA 管理）
  • 埋点管理按投放平台动态配置 + 「?」帮助（按平台查看：回传方式 / 点击参数 / 必传基础事件 / 优化事件 / 开发文档）
  • 各阶段在对应功能页完成配置（域名管理 / 打包管理 / 渠道管理 / 埋点管理）

5.2 域名管理

  • 4 种域名类型：主域名 / 推广域名 / 防封谷歌页 / 防封苹果页
  • 按类型动态字段：推广域名 → 跳转域名 + 落地指向；防封页 → 仿模板 + 落地主域名 + 救援
  • 防封救援：救援开关 / 强制弹窗 / 救援域名(多选) / 救援方案 / 救援奖金 —— 被封自动切换、带账号自动登录领奖金
  • 解析检测（检测中 → 生效）

5.3 打包管理

  • 新增渠道包：应用名称 / 版本号 / 打包域名 / 邀请码(0-20 计数，留空不使用)
  • 上传 iOS包(.ipa) / 安卓包(.apk) / iOS壳包 / 安卓壳包（WebView 套壳）
  • 列表含 邀请码 列；详情 / 下载 / 二维码 / 重新打包

5.4 埋点管理

  • 9 种埋点类型（按平台分组）：常规推广 / APK上架包 + Facebook/TikTok/Kwai/GTM-click + Facebook/TikTok/Kwai-API
  • 配置项按类型动态：click 类 = Pixel ID；API 类 = Pixel ID + Token + test_event_code
  • 平台页签（Facebook/TikTok/谷歌/Kwai）+ 埋点说明（必传基础事件 + 优化事件 + 事件映射 + 开发文档）
  • 测试回传（含 Facebook-API 5 步流程）

5.5 渠道管理

  • 新增渠道：渠道来源 / 绑定域名 / 落地指向(5选) / 埋点类型 / 动态参数 / 邀请码
  • 生成带渠道码推广链接；复制推广链接 / 推广二维码 / 停用 / 删除
  • 来源写入会员「归因来源」，闭环渠道 ROI

5.6 PWA 配置

一页双 Tab：域名列表 + 域名统计。
  • 域名列表：商户 / 域名 / 语言切换 / 内外链 / 备注 / 开启状态 / 最后修改；操作 编辑 · 跳转配置 · 页面配置 · 推送配置 · 发布
  • 域名统计：打开次数 / 打开人数 / 下载次数（按商户、域名、时间区间查询）
推广分发完整说明（SOP / 关联矩阵 / 投放渠道×端 / 回传逻辑）见 推广分发配置 · 完整说明。

七、设计与文案规范

非研发性质的统一规范，约束所有新旧页面：交互一致、控件一致、名词一致、提示语一致。底层原则：交互统一 · 控件统一 · 简洁 · 小白友好。

7.1 交互规范

  • 列表页通用 — 查询(条件过滤保留输入) / 重置 / 导出 CSV / 翻页 / 排序 / 时间快捷 / 说明 / 批量(勾选拦截+二次确认) / 自定义列(勾选后点保存生效·取消不改动) / 高级筛选(前5+折叠收起)
  • 筛选下拉来源真实 — 选项按字段映射真实内容（广告平台 / 回传类型 / 状态 / 域名类型 / 落地指向 等），首项「全部」；联动字段（域名←域名管理、渠道←渠道管理）一律下拉选用、不许手输
  • 表单弹窗 — 自适应尺寸；图片字段(图片/封面/图标)自动渲染为上传控件(选图→预览→移除)；图片缩略图悬停放大；限长输入带计数器(如邀请码 0/20)
  • 动态表单 — 域名类型 / 分发形态 / 埋点类型 / 投放平台 改变时配置项动态切换，切换不丢已填内容
  • 二次确认 — 三类操作必须弹「操作确认」：① 删除/移除/解除等不可逆操作 ② 批量操作（带勾选数量）③ 状态开关切换（如 领取返佣 / 对上级返佣 toggle）；其余操作不加确认，避免打断
  • 详情抽屉 — 头部固定（标题+关闭），内容区独立滚动；板块卡片化分组；可点字段（邀请人/代理路径/ID）蓝色并支持点击下钻或复制
  • 页签栏 — 子页以可关闭页签进入页签栏，新页签追加在末尾
  • 操作位次 — 行操作 ≤3 个直接平铺，>3 个收进「更多」；主操作（新增X）置于工具栏最左、蓝色实心；工具类按钮（刷新/自定义列/导出）置于工具栏最右、灰色描边

7.2 提示语规范

场景句式模板示例
成功反馈「已 + 动作」（对齐目标站），批量带数量；带数据明细的结果用「动作 + 完成/成功 + 详情」已删除 ｜ 已保存 ｜ 已批量禁用（12 条）；查询完成，共 28 条
查询反馈「查询完成，共 N 条」查询完成，共 28 条
拦截提示「请先 + 缺失动作」请先勾选要操作的数据 ｜ 请先选择商户
二次确认「确认 + 动作 + 对象？」不可逆的补一句后果确认对已选 12 条执行「拉黑」？ ｜ 确认删除该渠道？删除后渠道链接将立即失效。
开关确认「确认开启/关闭「字段名」？」+ 生效说明确认关闭「对上级返佣」？关闭后该会员产生的流水不再向上级计佣。
输入占位输入「请输入+字段名」；选择「请选择+字段名」；可留空注明请输入分组名称 ｜ 请选择商户 ｜ 留空则不使用邀请码
空状态「暂无数据」+ 可行动作暂无数据，点击「新增渠道」创建第一条
进行中「动作 + 中…」解析检测中… ｜ 打包中…
通用要求：① 句式统一用中文标点、不用感叹号、不暴露错误码/技术术语；② 确认弹窗标题统一「操作确认」，主按钮文案=动作动词（保存/删除/确认），副按钮统一「取消」；③ 同一动作全局同一句式（统一「已X」），禁止一处「已删除」另一处「删除成功」。

7.3 排版布局规范

  • 列表页骨架（自上而下） — 筛选卡（2–4 列栅格，高级筛选前 5 +折叠）→ 表格卡（工具栏：主操作左 / 工具右）→ 表格（复选框列居首、操作列居尾）→ 已选合计行（仅统计勾选行·实时更新；不勾选为 0）→ 分页（右下：共 N 条 / 页码 / 条每页 / 跳至）
  • 表单布局 — 弹窗内两列栅格，长字段（文本域/上传/说明）占整行；标签上置；必填标 *；逻辑分区用虚线分隔 + 蓝色小标题（如「自动归组条件」「分组权限」）
  • 详情抽屉布局 — 板块卡片自上而下：基本信息 → 归因来源 → 代理数据 → 注册/登录信息 → 业务数据；字段以 label:value 两列网格排布；新增字段红字标识、位置插入不改原布局
  • 色彩 — 主色蓝 #2563eb（主按钮/链接/激活页签/商户 pill）；成功绿 / 危险红 / 警示黄 / 停用灰；新增标识红字或橙色「新」tag；同义状态全局同色
  • 字号层级 — 页面标题 24 / 卡片标题 16 / 正文与表格 13–14 / 辅助说明 12；金额与 ID 用等宽数字（tabular-nums）
  • 对齐与间距 — 金额列右对齐；状态/操作列居中可选，文本列左对齐；卡片间距 14–16px、卡内边距 20–24px、控件间距 8px
  • 说明区 — 页面级口径说明统一放表格下方浅灰说明块（「说明：」开头），不混入表头或弹窗

7.4 名词术语规范

控件与名词全局一致；同一功能只允许一个叫法，旧名不再出现。
统一叫法禁用叫法 / 说明
分组管理禁用「用户分组 / 会员分组 / 分组表单」（列表+增改已融合为一页）
站内消息含原「推送消息」；「公告消息」=弹窗+滚动双页签
商户=租户隔离边界（集团→市场→商户）；与「三方商户」（支付上游商户号/昵称）严格区分，不得混写
行操作动词统一用 详情 / 编辑 / 删除 / 启用 / 停用；禁止 查看与详情、修改与编辑、移除与删除 混用
新增 X主操作统一「新增+对象」（新增分组/新增渠道）；禁止 添加 / 新建 混用

7.5 数据格式与状态规范

  • 金额 — 千分位 + 固定两位小数（1,834.66），右对齐；已选合计行同格式加粗
  • 时间 — YYYY-MM-DD HH:mm(:ss)；全局时区随顶栏（UTC+5:30），不混用相对时间
  • ID 类 — 会员ID / 代理ID / 订单号：蓝色可点 + 复制图标；多 ID 查询支持空格分隔
  • 脱敏 — CPF：123.***.***-01；银行卡：仅尾 4 位；手机号：中段 *；导出文件同样脱敏
  • 状态呈现 — 即时生效类用 switch（开启状态/领取返佣）；流程状态用色点+文字（待审核黄 / 已通过绿 / 已驳回红 / 停用灰）；不得同页混用两种形式表达同一状态
  • 空值 — 统一「-」；空表格用空状态文案，不留白
  • 导出 — CSV，文件名「页面名_YYYYMMDD」；超量截断须提示（如 超出 1000 条，已截取前 1000 条）
