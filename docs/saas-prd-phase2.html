一、目标与范围

二阶段聚焦五件事：

  • ① 会员管理深度迁移 — 按 SitINR 对照补全会员相关功能，按分类优化重新归属到 5 个模块
  • ② 顶部导航分类优化 — 8 大主 Tab 多列分组下拉，子页作为可关闭标签进入页签栏
  • ③ 快捷工作台 — 功能磁贴可增删 / 拖拽排序（本地持久），作为聚合入口
  • ④ 会员详情新增归因字段 — 在真实抽屉按指定位置注入红字字段（归因来源 / 归属层级 / 代理数据 / 注册登录）
  • ⑤ 推广分发配置（全新） 核心 — 域名 / 打包 / 埋点 / 渠道 / PWA + 配置向导 SOP
交付形式：以 localhost:8200 可点击原型 为准（真实交互，非占位）。本阶段在原型中共新增 38 个页面。

五、推广分发配置 二阶段核心

位置：运营管理 → 推广配置。把 域名 → 打包/PWA → 渠道 → 埋点 串成投放配置链，支持 安卓APK / iOS原生 / 安卓壳包 / iOS壳包 / H5链接 / PWA 共 6 种分发形态。

5.1 配置向导（标准作业 SOP）

单页分板块、可逐块配置；每阶段标注 负责角色 / 操作步骤 / 验收检查点 / 交付产出；完成后生成配置结果总览。
1 域名准备→ 2 物料打包 / PWA→ 3 渠道绑定→ 4 埋点回传→ 5 投放监控
  • 每个字段来源真实模块下拉：域名 ← 域名管理、渠道 ← 渠道管理、埋点平台 ← 埋点配置
  • 第 2 步按分发形态动态配置：APK 传 .apk + 应用名/版本/打包域名；壳包传壳包 + 壳访问URL；H5 / PWA 免打包（提示 + 跳 PWA 管理）
  • 第 4 步按投放平台动态配置 + 「?」帮助（按平台查看：回传方式 / 点击参数 / 必传基础事件 / 优化事件 / 开发文档）
  • 每步可「去对应功能页完整配置」跳转，向导页签保留

5.2 域名管理

  • 4 种域名类型：主域名 / 推广域名 / 防封谷歌页 / 防封苹果页
  • 按类型动态字段：推广域名 → 跳转域名 + 落地指向；防封页 → 仿模板 + 落地主域名 + 救援
  • 防封救援：救援开关 / 强制弹窗 / 救援域名(多选) / 救援方案 / 救援奖金 —— 被封自动切换、带账号自动登录领奖金
  • 解析检测（检测中 → 生效）

5.3 打包管理

  • 新增渠道包：应用名称 / 版本号 / 打包域名 / 邀请码(0-20 计数，留空不使用)
  • 上传 iOS包(.ipa) / 安卓包(.apk) / iOS壳包 / 安卓壳包（WebView 套壳）
  • 列表含 邀请码 列；详情 / 下载 / 二维码 / 重新打包

5.4 埋点管理

  • 9 种埋点类型（按平台分组）：常规推广 / APK上架包 + Facebook/TikTok/Kwai/GTM-click + Facebook/TikTok/Kwai-API
  • 配置项按类型动态：click 类 = Pixel ID；API 类 = Pixel ID + Token + test_event_code
  • 平台页签（Facebook/TikTok/谷歌/Kwai）+ 埋点说明（必传基础事件 + 优化事件 + 事件映射 + 开发文档）
  • 测试回传（含 Facebook-API 5 步流程）

5.5 渠道管理

  • 新增渠道：渠道来源 / 绑定域名 / 落地指向(5选) / 埋点类型 / 动态参数 / 邀请码
  • 生成带渠道码推广链接；复制推广链接 / 推广二维码 / 停用 / 删除
  • 来源写入会员「归因来源」，闭环渠道 ROI

5.6 PWA 配置

一页双 Tab：域名列表 + 域名统计。
  • 域名列表：商户 / 域名 / 语言切换 / 内外链 / 备注 / 开启状态 / 最后修改；操作 编辑 · 跳转配置 · 页面配置 · 推送配置 · 发布
  • 域名统计：打开次数 / 打开人数 / 下载次数（按商户、域名、时间区间查询）
推广分发完整说明（SOP / 关联矩阵 / 投放渠道×端 / 回传逻辑）见 推广分发配置 · 完整说明。

七、通用交互规范

  • 列表通用 — 查询(条件过滤保留输入) / 重置 / 导出 CSV / 翻页 / 排序 / 时间快捷 / 说明 / 批量(勾选拦截+二次确认) / 自定义列(实时显隐) / 高级筛选(前5+折叠)
  • 筛选下拉来源真实 — 选项按字段映射真实内容（广告平台 / 回传类型 / 状态 / 域名类型 / 落地指向 等），首项「全部」
  • 表单弹窗 — 自适应尺寸；图片字段(图片/封面/图标)自动渲染为上传控件(选图→预览→移除)
  • 动态表单 — 域名类型 / 分发形态 / 埋点类型 / 投放平台 改变时，对应配置项动态切换
