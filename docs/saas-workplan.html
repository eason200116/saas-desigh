2通用交互规范（所有列表页共用骨架）
全部列表页共用同一套交互骨架，从上到下固定为 筛选区 → 批量工具条 → 表格 → 分页 四段；控件与行为全局一致，规范对齐线上 SIT 租户后台（对照基准见 SIT 结构图谱，逐页核验见 8200 vs SIT 验收清单）。新建任何列表页必须遵循本节，不得另造控件或叫法。
区块 / 控件统一规则（所有列表页一致）
筛选区「商户 *」永远居首必填；常用条件在前，超过 5 项进「高级筛选」折叠；整区可「收起 / 展开」；时间范围用 开始 → 结束 双输入；底部右侧固定 搜索（蓝）/ 重置
快捷日期今天 / 昨天 / 本周 / 上周 / 本月 / 上月 / 所有；层级·报表类另支持 上一日 / 下一日 / 日 / 日区间 / 月 逐日导航
批量工具条专项批量按钮置于表格上方（如批量拉黑 / 拉白 / 禁用 / 启用…）；未勾选先拦截提示，执行前二次确认；底部「全选当前页」配合勾选列
表格单元格商户＝蓝色 pill；会员ID / IP＝蓝链接＋一键复制（ID 点击进详情）；金额右对齐＋表头点击排序；状态＝绿 / 红 badge 或行内 toggle 开关（切换必二次确认）；敏感字段脱敏（卡号 / 手机中段打码）；一格可堆叠多行（如申请 / 派单 / 更新时间）；新增字段红字标识
操作列纯文本链接：编辑 / 详情（蓝）、删除（红，二次确认）；冻结固定在表格最右（横向滚动不动、左侧带分隔阴影），任何浮动元素不得遮挡
自定义列每个列表右上角「⚙ 自定义列」，勾选实时显隐
合计行金额类列表带「页面合计 / 总计」双汇总行（金额 / U额）
分页器统一 共 N 条 · 页码 · 10 条/页 · 跳至 __ 页
弹窗新增 / 编辑 / 详情统一自适应尺寸（贴合内容不留白）；图片字段自动渲染为上传控件（选图 → 预览 → ✕ 移除）；复杂详情用弹窗内页签（如 订单详情 / 日志 / 会员 / 账变）

设计内核一句话：「商户隔离 ＋ 可收起筛选 ＋ 标准表格 ＋ 文本链接操作 ＋ 自定义列」为骨架；交互统一、控件统一、简洁、小白友好。后续新增页面以本节为验收口径。
