说明：
  • 放置粒度：每个「配置项 = 可编辑值」后挂一个小图标（等级配置=每个数值单元格；经验值配置=兑换金额字段）。图标极小、默认浅灰不抢视线，hover/点击变绿。
  • 弹层内容：固定 3 列「操作时间 / 操作人员 / 操作内容」；默认展示最近 4 条，底部「查看全部记录 →」跳系统日志并带该配置项筛选。
  • 数据来源：复用「系统管理 · 系统日志」字段（logDateStr / userName / logInfo），按 该页面+该配置项 过滤。
  • 只读：弹层仅查看，不可编辑；点击空白处或 ✕ 关闭。
