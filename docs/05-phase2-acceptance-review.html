一、先记住 5 句话——好功能长什么样

每个功能都该同时满足下面 5 条。心里有这 5 把尺，后面一条条点就快了。

简称一句话怎么算"没做到"（❌ 的样子）
真能用是真能干活，不是摆样子点搜索列表不变 / 点导出没下载到文件 / 保存了列表还是老样子
有回应每点一下都有反应；删除、批量这种"危险动作"会先问你"确定吗"点完没任何提示 / 删除批量不问就直接干了
找得到每个功能都能从顶部菜单点进去，菜单上还带"新/原"小标菜单里没有这一项 / 点不进去 / 没有新旧标
有出处这些功能不是凭空造的，旧后台里基本都有对应来源找不到旧后台的对应功能
一个样全站按钮名字、长相一致（都叫"启用/停用、编辑、详情"）同一个意思这里叫"开启"那里叫"激活"
