概览：本期五大交付

一句话：把旧后台（SitINR）里会员相关的功能搬进新后台并顺手升级——共 22 个功能页、一套新导航框架、一套「会员从哪儿来」的归因体系、一条广告投放配置链。交付以 localhost:3100 可点击原型 为准（真实交互、非占位）。

① 会员管理深度迁移 — 按 SitINR 对照补全会员相关功能并重新归类，共 22 个功能页（会员管理 3 / 运营管理 12 / 报表管理 2 / 风控管理 2 / 配置中心 2 / 系统管理 1）。
② 顶部导航分类优化 — 8 大主 Tab 多列分组下拉（mega menu），「风控管理」「配置中心」从会员子项提升为一级模块；菜单项带 新/原 角标。
③ 多标签页签栏 — 功能页以页签多开并存、切换、关闭。
④ 会员详情归因字段 + 会员列表增强 — 会员详情按指定位置注入 27 个红字归因字段；会员列表同步红色列 +「领取返佣 / 对上级返佣」行内开关。
⑤ 推广分发配置 — 本期开放 渠道管理 / 域名管理 / 防封救援 / 解析检测记录 4 页，覆盖「域名 → 渠道 → 推广 → 获客归因」闭环前半段。
本期同步移除：KW认证 / CPF认证 / 代理关系导入、活动相关配置（首充管理 / 活动资讯 / 邀请任务 / ARB提现 等）与 会员洗码管理；「会员分组 + 分组表单」融合为「分组管理」一页。

二、归因体系 + 会员详情

解决「这个会员从哪儿来」——注册时按优先级判定来源并固化，详情页以红字字段呈现完整链路。

归因判定规则（优先级）

① 广告投放› ② 邀请来源› ③ 官方直推› ④ 自然流量

注册时按上述优先级判定首个命中的来源，写入会员档案并固化不再变更。共 5 大归因类型 × 18 种情况的穷举矩阵覆盖各种进入路径。

归因判定流程（5 步固化）

进入→ 采集（埋点：激活/注册/登录/首充/付费）→ 判定（按优先级）→ 固化（写档案）→ 展示（详情红字）

会员列表 · 新增内容定义

本期会员列表在原 SIT 排版基础上，新增 2 个行内配置开关与一批展示列，并按 9 类目分组表头重排。以下逐项解释含义与作用。

领取返佣 行内开关

控制该会员是否可领取自己的返佣。开=可领取、关=不可领取。供运营按会员资质开关返佣资格。点击弹二次确认「确认要开启/关闭该会员的「领取返佣」吗？」，翻转后 Toast。

对上级返佣 行内开关

控制该会员产生的有效投注流水是否为其上级代理计提返佣。开=计提、关=不计提。常用于内部号 / 测试号关闭，避免污染代理佣金结算。点击弹二次确认，翻转后 Toast。

新增展示列 注册设备 · 登录设备 · 代理数据（原型实际「新」标列 = 10 个）
注册域名新注册时进入的域名（属本商户）。
注册设备号新注册时稳定设备 ID（App 端有值，网页端显 -）。
注册浏览器指纹新注册时浏览器指纹（网页端有值，App 端显 -）。
上次登录设备新最近一次登录的客户端设备。
上次登录设备号新最近一次登录的稳定设备 ID。
上次登录浏览器指纹新最近一次登录的浏览器指纹。
一级代理新该会员所在代理树的顶级（根）代理。
直接上级代理新代理树中该会员的直接父节点。
佣金模式新代理收益方式：返佣 / 返利。
对上级返佣新行内开关：该会员有效投注是否为上级计提返佣。（『领取返佣』开关为原有列，未标新）
表头：原型当前为扁平单行表头（早期「9 类目分组表头 / 逐组折叠」方案已在原型移除）；新增列以低调「新」角标区分，自定义列弹窗按列勾选、保存后生效。

5.1 通用验收口径（铁律）

  • 数据真实性：所有数据/交互/代码取自 /Users/eason/v1 源（SitINR 源码/UAT），无源标「新」并先问、不臆造。
  • 真实交互：导出真实下载 CSV、搜索真实过滤、排序真实重排、表单保存真实回写、删除真实移除——每步配 Toast。
  • 商户隔离：筛选区商户首位 + 表首商户列 + 商户视角隐藏商户列 + 切换即时重渲染。
  • 反馈完整：每个操作必有反馈；危险操作二次确认；保存校验失败标红问题字段 + 顶部错误面板列原因。
  • 动态配置正确：VIP 行内编辑无弹窗去 ID；返佣同级五大类费率之和 >4% 拦截；等级/经验逐级递增、数值≥0。
  • 归因注入：会员详情 27 红字字段在指定位置、布局不变、可点可复制；同IP/设备数值可下钻风控页。
