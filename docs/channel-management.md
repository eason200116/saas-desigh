# 渠道管理（Channel Management）· 记录

> 记录时间：2026-06-09 ｜ 归属模块：运营管理 / 推广配置 ｜ 关联：打包管理、埋点管理、会员「归因来源」字段

## 一、定位
包网商户推广的**"入口配置层"**：为每个推广来源（FB / Google / TikTok / TG / 代理…）建立一个**渠道**，生成可追踪的推广链接，绑定落地页 + 埋点 + 推广域名；用户从渠道注册后，把来源**固化进会员「归因来源」**，最终闭环到**渠道 ROI 报表**。

## 二、在推广闭环中的位置
```
打包(壳包/分包) → 埋点(像素/回传) → 【渠道】 → 归因落地(注册写来源) → 渠道 ROI 报表
```
渠道是把"广告流量"与"会员归因"对接起来的枢纽。

## 三、核心字段
| 字段 | 说明 |
|---|---|
| 渠道号 / 渠道名称 | 唯一标识 + 可读名（如 FB-印度-01）|
| 渠道分组 | 按来源归类（Facebook / Google / TikTok / TG / 代理…）|
| 归属代理 | 渠道挂在哪个代理下，用于代理业绩归集 |
| 推广域名 | 与主站域名分离，便于防封 / 轮换 |
| 落地页(LP) | 按活动 / 渠道配不同落地页 |
| 关联埋点 | 绑定 Meta / Google… 像素 + 服务端回传 |
| 推广链接 | 自动生成，带**渠道码 + 邀请码**，并透传点击ID（fbclid / gclid / ttclid）|
| 统计 | 注册数、充值数（可扩：首充率、ROI）|
| 状态 | 启用 / 停用 |

## 四、核心操作
- 新增 / 编辑 / 停用 / 删除渠道
- **生成 & 复制推广链接**、**推广二维码**
- 绑定 落地页 / 埋点 / 推广域名 / 归属代理
- 进阶：渠道分组、批量操作、渠道效果对比

## 五、与归因的闭环
用户点渠道链接（带渠道码）→ 注册时写入会员的 **注册渠道 / 邀请码 / 主归因 / 推广平台名称** → 会员详情「**归因来源**」板块展示链路（会员→渠道→直接上级代理→一级代理→域名→商户）→ 报表按渠道看 注册 / 充值 / ROI，并把代理业绩归集到「归属代理」。

## 六、当前实现 & 数据来源
- **实现**：`localhost:8200` → 运营管理 / 推广配置 / **渠道配置**（直达 `?open=channel-config`）
  - 列表：渠道号 · 名称 · 分组 · 归属代理 · 推广域名 · 落地页 · 关联埋点 · 注册数 · 充值数 · 状态
  - 行操作：详情 · 编辑 · 复制推广链接 · 推广二维码 · 停用 · 删除
- **源系统对应表（SitINR）**：`tab_Channels` / `Source` / `SourceUse` / `LandingPageConfig` / `LandingPageManagement` / `EventRegionConfig`（域名像素 / 落地页 / 渠道来源）
