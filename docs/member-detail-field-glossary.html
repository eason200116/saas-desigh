① 基本信息组

3 字段
字段名词解释应用场景异常情况
经营币种currency会员所属市场/商户锁定的结算币种，注册即固定、终身唯一，所有金额以此计。财务分币种统计；提现/充值限额按币种配置；同集团跨市场金额不可直接相加。跨市场合并报表禁止直接求和（须分币种列示）；币种错绑只能注销重注册，不可修改。
邀请人inviterId邀请码发起人 ID（通常=直接上级代理），点击可下钻该用户详情。裂变追踪、代理树构建依据、佣金归属判定。无邀请码注册则为空；邀请人被注销/冻结时，代理关系仍保留快照不随之改写。
访问端accessClient最近一次访问的客户端类型，枚举 pc/h5/安卓/ios/安卓壳包/ios壳包。设备分布分析、端侧问题定位、APP 下载引导、风控识别。壳包内 WebView 以外层壳判定；UA 被篡改/无法识别时记「未知端」并保留原始 UA。

② 归因来源组

7 字段
字段名词解释应用场景异常情况
主归因mainAttribution注册来源唯一归类（自然流量/广告投放/官方直推/邀请来源 + 未知），优先级唯一、命中即停。获客成本核算、渠道质量评估、ROI 分母；报表按主归因拆分。邀请链接+UTM 并存→判邀请来源，UTM 留辅证并标「裂变获客」；全部无法识别→未知来源并记失败原因。
推广平台名称promoPlatform识别出的外部推广平台。带平台点击ID精确识别：Google（gclid）、Meta/Facebook（fbclid）、TikTok（ttclid）、Bing（msclkid）；经 utm_source 识别：Instagram、YouTube、Telegram、WhatsApp、X（Twitter）、Snapchat、Kwai、ShareChat、Line、Zalo；以上均未命中或无参数 → 其他。广告投放平台维度效果与对账；KOL/平台归集。多平台参数冲突按点击ID优先级判定；不可识别→其他；App 安装归因另行设计。
注册渠道regChannelId注册时命中的后台定义渠道ID（如 pc001=Facebook推广1），挂在域名之下的来源归因容器。渠道维度注册转化统计、渠道质量与结算。未命中任何渠道→落该经营单元默认自然流量兜底渠道（不可删除/不关注册）；渠道关闭不改历史快照。
登录渠道loginChannelId会员最近一次登录命中的渠道ID，可与注册渠道不同。活跃来源分析、再营销渠道评估、回流入口判断。直接访问无渠道参数时显示默认/空；跨商户域名进入应判异常并拦截。
搜索引擎searchEngine由 referrer 来源域名识别。可识别引擎：Google、Bing、Yahoo、Yahoo! Japan、DuckDuckGo、Ecosia、Startpage、Brave Search、Ask.com、AOL、Mojeek、You.com、Perplexity、Qwant、Swisscows、MetaGer、SearXNG、Lycos、Excite、Dogpile、OneSearch、Gibiru、Presearch、Yandex、Mail.ru、Rambler、Naver、Daum、goo、Seznam、Onet、WP（Wirtualna Polska）、Coc Coc、Sapo、Eniro、Najdi、Walla；中国引擎（百度/搜狗/360/神马等）及未列出者一律归「其他」；无 referrer 记直接访问。SEO 效果评估、自然流量质量。referrer 被剥离（隐私模式/referrer 策略）→记直接访问；非搜索来源（如经 Meta 进入）→其他。
邀请码inviteCode会员注册实际使用的邀请码，关联邀请人/代理ID。代理树绑定、裂变奖励触发、邀请人佣金归属。码失效/过期/跨商户→可注册但不绑代理并记原因；活动邀请码额外记 invite_activity_id。
邀请类型invite_type邀请来源细分：正常邀请（invite_type=normal，个人邀请）/ 活动邀请（invite_type=activity，裂变获客，含 invite_activity_id）。区分纯邀请与活动裂变；活动邀请触发活动奖励并标裂变。活动码过期但邀请链接有效→降级为正常邀请；两类标记冲突时以活动邀请优先并记原因。

③ 归属与层级组 ※ 仅研发时查看，后续上线会隐藏掉

3 字段
字段名词解释应用场景异常情况
集团groupId最高归属与控制方，统管旗下多市场与商户，是层级主线顶层。多商户汇总报表维度、全局口径与策略。集团下不同市场币种/语言不同，跨市场指标不默认混合。
市场marketId按国家/地区划分的经营单位，承载币种、语言与本地化口径（INR · hi）。本地化配置、风控阈值与活动档位的边界。同集团跨市场金额/非金额指标按规则分开，不混用。
商户merchantId实际运营主体与合同/计费/团队归属边界，是会员数据隔离的经营单元。多商户数据隔离、权限边界、经营责任承载。在 A 注册的会员进入 B 视为 B 的新会员；会员/钱包/订单/活动/佣金不跨单元混用。

④ 代理数据组

9 字段
字段名词解释应用场景异常情况
一级代理rootAgentId该会员所在代理树的顶级（根）代理。总代业绩归集、分成顶层、大代理线监控。自身即根则显示自己/空；代理线超最大层级后新增不再挂树。
直接上级代理parentAgentId代理树中该会员的直接父节点（=邀请人）。一级返佣计算、直属关系展示。平台直客无直接上级；不提供转代，划拨只改经营归属不改代理树位置。
代理层级agentLevel当前深度 / 最大允许层级（如 3 / 10）。多级返佣分成层级、防无限级嵌套。达上限后下级不再建代理关系；层级数须与代理路径长度一致，否则告警。
代理路径agentPath根→本会员的完整代理 ID 链。超过 3 层时仅展示「一级 → … → 直接上级 → 本人」（中间层折叠），点击查看整条线全部代理信息。上下级关系核查、多级返佣溯源、闭环排查。≤3 层时全量展示不折叠；路径出现重复 ID→闭环异常；中间代理注销→以快照为准。
佣金模式commissionMode代理收益方式两类：返佣=投注流水返佣 / 返利=亏损分成返利。代理结算口径、不同代理线差异化激励。同线不同级可不同模式；模式变更只对变更后业绩生效，历史按原模式结算。
返佣等级rebateLevel会员自身的返佣等级/档位，决定其投注流水返佣比例（如 Lv3=0.5%）。返佣计算、等级化激励、与 VIP/活跃度联动调整。等级变更只对变更后流水生效，历史按原等级结算；无返佣资格时为 0 级/空。
是否给上级返佣rebateToUpline该会员产生的有效投注流水是否为其上级代理计提返佣。控制返佣链路；内部号/测试号可关闭不计佣。关闭后上级不再因其流水获佣，但代理树关系保留；与代理状态独立。
是否可领取返佣canClaimRebate该会员是否被允许领取自身累积的返佣（资格/开关），区别于「是否领取返佣」的已领状态。风控冻结期禁领、达标后开放领取、活动期临时管控。冻结/风控期间置否仍累计不发；恢复后可补领，留审计。
代理状态agentStatus代理资格状态（生效/冻结/注销），与用户账号状态独立。冻结作弊代理返佣但不影响其玩家身份；注销取消资格保留历史。账号启用但代理冻结/注销时，下级业绩不再计佣；状态变更留审计。

⑤ 注册登录信息组

8 字段
字段名词解释应用场景异常情况
注册端regClient会员注册时使用的客户端，枚举 pc/h5/ios/安卓/ios壳包/安卓壳包。注册端转化分析、APP 渗透率。UA 被篡改记未知；注册端与长期登录端差异大→疑养号/接管。
注册设备号regDeviceId注册设备的稳定唯一标识（安卓/iOS 原生包采集的设备 ID）；为后续原生包预留，壳包/H5 阶段可能为空或临时值。多开/养号识别、设备维度风控、配合防环与同设备聚合。壳包/H5 取不到稳定 ID→为空或记临时值，待原生包补采；设备号被重置/越狱伪造→标风险。
是否模拟器isEmulator注册/登录设备是否为模拟器/虚拟环境。批量注册与作弊识别、风控拦截。反检测伪装可能漏判；云真机/越狱设备单独标记。
同设备账号数sameDeviceAccountCount与本会员同一设备号注册/登录的账号总数。多开/工作室/养号识别、设备维度风控聚合。取不到稳定设备号时不计；家庭共享设备可能误判，需结合行为研判。
登录端loginClient会员最近一次登录的客户端，枚举同注册端。活跃端分析、注册端与登录端一致性风控。登录端频繁跨端切换+异地→异常登录告警。
登录设备号loginDeviceId最近一次登录设备的稳定唯一标识（原生包采集）；为后续原生包预留。常用设备识别、异常设备登录监控、同设备多账号聚合。登录设备号与注册设备号长期不一致→疑账号转手/接管；取不到时待原生包补采。
注册域名regDomain会员注册时进入的域名（属本商户），完成主线 商户→域名；域名定上下文，渠道定来源。域名类型：主站/推广/落地/备用。渠道入口落到确定经营上下文；推广域名效果归集。仅有域名而无渠道时落该单元默认自然流量；域名删除/启停不改写历史会员的注册域名快照。
登录域名loginDomain会员最近一次登录进入的域名，可与注册域名不同（如注册走推广域名、登录走主站域名）。回流入口分析、主站/备用域名切换监控。跨商户域名进入应判异常并拦截；域名被封后登录走备用域名属正常切换。
