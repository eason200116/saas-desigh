# 原型图规范 · SaaS 后台（平台端 / 商户端）

> 适用：`saas-desigh/prototypes/` 下所有 HTML 原型，以及 V3 目标站（`Ar_V3_LottoPlatformDesign`）页面设计。
> 依据：`KNOWLEDGE-BASE.md` §3.3（截图提取控件规范）/ §6（设计原则）+ `agent.md` §7–§10 + 现有原型实测 token + V3 动态主题体系。
> 维护时间：2026-06-13。**本文件为"规范"，与"open questions"分写；冲突项以本文为准。**

---

## 0. 定位与适用范围

- 平台端、商户端**只做电脑版管理工作台**（不做移动端适配）。
- **单品牌与多品牌复用同一套前端**，不为单品牌另做页面；单品牌＝多品牌的"锁定态"，不是另一套产品。
- 设计收敛顺序：多品牌多市场 → 多品牌单市场 → 单品牌单市场。

## 1. 文件组织与命名

| 目录 | 职责 |
|---|---|
| `prototypes/` | 可直接打开审阅的 HTML 原型 |

- 单文件自包含：HTML + 内联 `<style>` + 内联 `<script>`，**不依赖外部构建**，双击即开。

- 新需求先建 `REQ-xxx` 需求包，再进入原型。

## 2. 设计底层原则（所有原型必须遵循）

1. **交互统一** — 相似功能交互方式一致。
2. **控件统一** — 全局同一套控件；控件与名词不一致时**先问，不擅自新造**。
3. **交互简洁** — 能一步完成不做两步。
4. **小白友好** — 入口明显易找、操作有文字引导、状态有视觉反馈、重要操作有二次确认。

**配置类页面专项原则：**
- 先展示**原配置（原值）**，再做变更。
- 提交前展示：作用对象 · 原值 · 提交后值 · 来源层级 · 差异摘要。
- 复杂配置不能只"选方案"，必须能**编辑方案细节**。
- 数组类配置支持**新增 / 修改单条 / 移除单条**，禁止整套误替换。

```
┌─────────────────────────────────────────────────────────┐
│ 顶栏(深色 #1e293b)  Logo+⏱时间 | 集团▾·商户标签·切换 |     │
│   5模块导航(带▾) |  ⛶全屏 | 在线·出入款·消息(图标+badge) | 头像▾ │
```

## 4. 视觉 Token

> V3 目标站采用**语义 token 驱动的动态主题**（主色 `accent` 商户可配置）；原型可写死，但**语义角色必须对应**，不得自创第六种状态色。

### 4.1 颜色（按语义角色）

| 角色 | 默认值 | 用途 |
|---|---|---|
| accent / brand 主色 | 后台蓝 `#0960bd`（截图基准，动态可配） | 主按钮、选中、链接强调 |
| link 链接 | `#2f74e6` | 表格操作列、文字链接 |
| success 成功 | `#13a884` / 浅 `#e8f7f2` | 解冻、启用、成功标签 |
| warn 警告 | `#d97706` / 浅 `#fff3e0` | 冻结、待处理、警告标签 |
| danger 危险 | `#e0524d` | 删除、待出款金额、危险标签 |
| info 信息 | `#e3f2fd` 底 | 信息标签、提示 |
| text 正文 | `#2c3344` | 主文字 |
| muted 次要 | `#8b93a3` | 辅助文字、占位 |
| border 边框 | `#e8ebf1` | 卡片/表格分隔 |
| card 卡面 | `#ffffff` | 卡片背景 |
| bg 页面底 | `#f0f2f5` | 页面背景 |
| 顶栏深色 | `#1e293b` | 顶栏 |

> ⚠ 会员端（member-app）为**绿色系**，与后台蓝系区分。早期原型 `group-admin.html` 用绿色主色属历史遗留，新原型统一以语义角色对齐后台蓝系。

### 4.2 字体 / 圆角 / 其它

- 字体栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 圆角：卡片/按钮 `8px`（主）、标签/输入 `4px`、大卡 `10px`
- 表格密度：中等行高，表头蓝灰底加粗

## 5. 控件规范

| 控件 | 规范 |
|---|---|
| **筛选区** | 白底卡片 + 网格布局；**商户为必填带红星**；右侧依次「搜索(蓝)」「重置(白)」「收起」「自定义列」 |
| **快捷时间** | 固定 7 项：今天 / 昨天 / 本周 / 上周 / 本月 / 上月 / 所有 |
| **表格** | 蓝灰表头；操作列用蓝色文字链接（非按钮）；底部分页 + **页面合计 / 总计** 行 |
| **自定义列** | 所有列表页统一支持列显隐配置（SitINR 列固定，此为统一增强） |
| **按钮** | 蓝色主（搜索/新增/确认提交）· 橙色警告（冻结）· 绿色确认（解冻/启用）· 白底次（导出/重置/取消） |
| **状态标签** | 绿成功 / 橙警告 / 红危险 / 蓝信息 / 灰禁用——**五色封闭，不新增** |
| **Tab 弹窗** | 复杂详情用多 Tab 弹窗（如系统用户 4Tab、会员详情 6Tab、银行卡 6Tab） |
| **批量操作** | 列表支持勾选 + 批量动作条（拉黑/分组/赋权/指派等） |

## 6. 交互规范

- **散页聚合为 Tab**：同域多个页面整合为单页多 Tab（财务/会员/游戏均遵循）。
- **重要操作二次确认**：删除、冻结、批量资金处置、发布等。
- **状态即时反馈**：操作后给出成功/失败提示，loading 态明确。
- **配置发布门控**：保存 → 发布两步（如集团后台），发布前展示差异摘要。
- **多商户筛选**：所有数据页支持商户下拉筛选；顶栏支持集团→商户视角切换。

---

## 7. 层级与多商户规范

层级链（固定，禁止臆造中间层）：

```
集团 → 市场 → 商户 → 域名 → 渠道 → 会员
```

- **商户是数据隔离边界**（无品牌层）。
- 平台端跨商户视角，商户端被锁定在单商户视角。
- 字段层级来源在配置页须显式标注（集团级/市场级/商户级）。
