归因字段说明

字段示例值含义 / 用途
主归因代理（邀请推荐）来源的最终归类，按 P1→P4 优先级唯一确定，是归因分析的核心维度。
推广平台名称Meta（Facebook）付费广告来源的投放平台，用于核算各平台拉新成本 / ROI。
注册渠道ag010（代理2250100专属链接）注册时命中的具体渠道码 / 专属链接，定位到代理或广告系列。
登录渠道ag010（代理2250100专属链接）每次登录记录的渠道，与注册渠道对比可看用户活跃入口是否漂移。
搜索引擎其他 / Google自然搜索来源时记录具体搜索引擎。
邀请码AGENT100代理 / 活动邀请码，关联邀请人与返佣关系。
邀请类型正常邀请（个人邀请）区分个人邀请 / 活动邀请 / 系统派发等，影响奖励与风控规则。
判定要点：
· 优先级唯一归因：一个用户只归一个「主归因」，按 P1 代理邀请 → P2 付费广告 → P3 自然搜索 → P4 自然流量 自上而下命中即止，避免重复计数。
· 注册 vs 登录：归因字段在注册时固化；登录渠道每次更新，便于分析「拉新来源」与「活跃来源」差异。
· 与会员详情「归因来源」板块、会员列表归因红列一一对应；「归属与层级」（集团/市场/商户）属组织维度，不在归因流程内。
