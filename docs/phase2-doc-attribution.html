④ 归因说明
归因体系（盖章 / 优先级 / 五步固化）+ 归因穷举矩阵（按主类型分组卡片流 · 整宽 5 步脉络图）。
给每个新注册会员盖一个「从哪儿来」的章——广告带来的、朋友邀请的、官方推广来的、还是自己搜来的。注册时盖下、永不再改；之后算广告费值不值、佣金分给谁，全凭这个章。
环节说明
判定优先级广告投放 ＞ 邀请来源 ＞ 官方直推 ＞ 自然流量（命中即停、就高不就低；全部解析失败并入自然流量）
五步固化① 进入（点推广/广告/邀请/搜索链接）→ ② 采集来源信号（渠道码 / 邀请码 / UTM / clickid / referrer / 指纹·IP）→ ③ 判定（优先级唯一）→ ④ 固化（注册成功一次性写入，注册后不可改写）→ ⑤ 展示（详情红字 + 列表红色列）
27 红字分组归因来源 / 代理体系 / 注册·登录设备 三组；详情红字按位置注入、布局不变；会员列表同步红色新列（自定义列可显隐）。逐字段定义见《新增字段介绍》。
并存规则邀请链接 + 广告 UTM 并存 → 判广告投放，邀请码留作辅证、仍挂代理树计返佣并标「裂变获客」；邀请类型再分 正常 / 转盘活动 / 邀请任务
登录另记「登录渠道」每次登录另行记录，用于对比拉新来源与活跃来源（与注册渠道可不同）

归因穷举矩阵（5 大类型 × 18 种情况）

按归因类型分组，每条归因一张卡：头部为触发条件，下方整宽展开该归因的完整 5 步脉络图（来源 → 入口 → 注册 → 采集 → 留存）。
