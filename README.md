# SaaS Design Prototype Index

当前目录按用途分为两类：

- `docs/`：体系文档与交接说明。
- `prototypes/`：可直接打开审阅的 HTML 原型。

主要入口：

- 主体系文档：`docs/v2-core-flows.html`
- 当前交接说明：`docs/handoff.md`
- Agent 基本原则：`agent.md`
- 需求文件体系规范：`docs/standards/product-requirements-file-system.md`
- 项目级产品上下文：`docs/product/README.md`
- 需求包目录规范：`docs/requirements/README.md`
- 需求包模板：`docs/templates/requirement-package-template.md`
- VIP 配置中心原型：`prototypes/vip-config-center.html`
- 风控规则配置中心原型：`prototypes/risk-config-center.html`

说明：

- 平台端、商户端原型后续只维护电脑版。
- 后续新增需求必须先建立 `docs/requirements/REQ-xxx-*` 需求包，再进入原型和开发拆分。
