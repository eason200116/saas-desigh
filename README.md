# SaaS Design Prototype Index

当前目录按用途分为三类：

- `docs/`：体系文档与交接说明。
- `prototypes/`：可直接打开审阅的 HTML 原型。
- `assets/screenshots/`：原型验证和历史截图记录。

主要入口：

- 主体系文档：`docs/v2-core-flows.html`
- 当前交接说明：`docs/handoff.md`
- VIP 配置中心原型：`prototypes/vip-config-center.html`
- 风控规则配置中心原型：`prototypes/risk-config-center.html`

说明：

- 平台端、商户端原型后续只维护电脑版。
- 移动端截图仅保留为历史参考，不再作为当前设计目标。
